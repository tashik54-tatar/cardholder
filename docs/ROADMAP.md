## Дизайн-решения

- **Шрифт:** Inter — ближайший свободный аналог SF Pro (шрифт «hello» при загрузке macOS), вес Light/Regular
- **Фон:** градиент + полупрозрачный повторяющийся узор из иконок (стиль фона чатов Telegram)
- **Главный экран:** у карт с фото лицевой стороны — только фото (без названия); у карт без фото — только название магазина
- **Минимализм:** ничего лишнего, лёгкая БД, офлайн-first
