# Мои карты (Cardholder)

**Скидочные и бонусные карты — всегда под рукой, офлайн.**

Добавь карту фото или сканом — и покажи штрихкод/QR с экрана на кассе.

</div>

## Возможности

- **Добавление карты за пару шагов**: сфотографируй сторону со штрихкодом или выбери готовую картинку (можно скриншот) — штрихкод/QR распознаётся автоматически; обрезка лицевой стороны сразу в формате банковской карты
- **Код крупно на кассе**: тап по карте — штрихкод или QR на весь экран на белом фоне, уверенно читается кассовым сканером
- **Фото сторон**: лицевая и оборотная стороны с ручной обрезкой; на главном экране карта показывается лицевой стороной, у карт без кода — обе фотки
- **Полное редактирование**: название, код, фото — всё меняется позже через карандаш на странице карты
- **Резервная копия**: экспорт/импорт CSV в настройках
- **Офлайн-first**: всё хранится на устройстве, сеть не нужна
- **Тёмная/светлая/авто тема**, анимации, фон в стиле Telegram

## Стек

| Компонент | Технология |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose (Material 3) |
| База данных | Room |
| Камера | CameraX |
| Распознавание кодов | ML Kit Barcode Scanning (офлайн) |
| Минимальный Android | 8.0 (API 26) |
