# Cardholder (Кархолдер)

Минималистичное Android-приложение для хранения скидочных и бонусных карт.

## Возможности (цель v1.0)

- Добавление карт сканом штрихкода / QR с камеры или из файла
- Лицевая и оборотная (со штрихкодом) сторона карты, ручная обрезка фото
- Главный экран: лицевые стороны карт (или названия — если фото нет)
- Тап по карте → штрихкод / QR крупно для предъявления на кассе
- Импорт и экспорт карт в CSV
- Нижнее меню: «+» (добавить) и «⚙» (настройки)
- Минималистичный интерфейс: градиентный фон с полупрозрачным узором (в стиле Telegram), нестандартный шрифт

## Стек

| Компонент | Технология |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose (Material 3) |
| База данных | Room |
| Камера | CameraX |
| Распознавание кодов | ML Kit Barcode Scanning (офлайн) |
| Минимальный Android | 8.0 (API 26) |
